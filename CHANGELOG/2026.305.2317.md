### Which check discriminates on THIS edit

The edit removes `yaml:` tags; the shipped test reads `json:` tags, which are byte-identical before
and after, so the test does not fail on the edit itself — it is the guard against the projection
drifting from its schema, not proof of the retag.

**The check that discriminates on the edit is the gate this repo is graded on**, and it runs in CI on
every PR here: `opencharly/.github`'s reusable `candy-validate` workflow splices the package clause
onto `candy/plugin-cua/schema/*.cue`, runs `cue exp gengotypes` at `cue@v0.16.1`, and diffs the
committed file — red (76 changed lines) before this change, empty after it.
